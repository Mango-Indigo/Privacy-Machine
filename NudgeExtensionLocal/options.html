Welcome to Privacy Machine

In the digital era, privacy is worth its weight in gold.

This extension aims to personalise the journey to privacy. It does this by analysing your personality type and using prompts specialised for you.

Currently, this extension uses Myers-Briggs Type Indicators(MBTI) to analyse your personality. See the image below for an explanation of the MBTI personality type.

Choose your Personality Type

Type some text in the box below and press the process button and this extension will analyse your personality using your text.



Press the save button if you are happy with our analysis or manually change your personality type and press save.
