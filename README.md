# Privacy-Machine
----------------------------------------------
CONTENTS
----------------------------------------------
this file contains four folders:<br>
1. Python Notebook: <br>
	&emsp; contains the jupyter notebook that trained and tested classifier models
2. NudgeExtension: <br>
	&emsp; contains extension folder
3. NudgeExtensionLocal: <br>
	&emsp; contains extension folder for local server 
4. Local Python Script: <br>
	&emsp; contains folder with the python script that runs on the heroku server (virtual environments and git not included)

--------------------------------------------
INSTRUCTIONS - Extension (THIS VERSION IS REDACTED)
--------------------------------------------
1. On Chrome Menu --> Extensions --> Manage Extensions 
2. On the Extensions page, select Developer Mode
3. Click Load unpacked and select the NudgeExtension Folder
4. On the extension called Privacy Machine, go to options (either via the popup or by right clicking options)
5. Enter text in the textbox and click Process Text and then Save the personality or set your own personality
6. Notifications will trigger when a password field is input.

--------------------------------------------
INSTRUCTIONS - Extension Local
--------------------------------------------
1. Open the app.py file in Local Python Script folder
2. Run the file using an IDE
3. On Chrome Menu --> Extensions --> Manage Extensions 
4. On the Extensions page, select Developer Mode
5. Click Load unpacked and select the NudgeExtensionLocal Folder
6. On the extension called Privacy Machine, go to options (either via the popup or by right clicking options)
7. Enter text in the textbox and click Process Text and then Save the personality or set your own personality
8. Notifications will trigger when a password field is input.

--------------------------------------------
Requirements
--------------------------------------------
For Extension Local: A python IDE, The conda libraries in python, The flask, flask_cors libraries in python
